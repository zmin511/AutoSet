## Риски

- Массовое изменение тегов может затронуть большую медиатеку.
- Engine DJ может после пересканирования перезаписать базу из файлов, если файл не был обновлен.
- Внешние API могут давать неверные стили или не находить релизы.
- Русские пути/названия чувствительны к кодировке; нельзя снова возвращаться к поиску треков только по строке `path`.
- Отсутствие автотестов повышает риск регрессий в `set_app.py` и `index.html`.
- Если `mutagen` не установлен в среде запуска AutoSet, запись тегов в файлы не сработает; зависимость указана в `requirements.txt`.

## Зависимости

- Python 3.11+ по portable README.
- `mutagen>=1.47,<2`.
- SQLite-база Denon Engine DJ `m.db`.
- Музыкальная папка `F:\Music`.
- Для online style lookup:
  - Discogs доступен как основной источник;
  - MusicBrainz доступен как fallback;
  - Last.fm требует `LASTFM_API_KEY` или файл `set_app\lastfm_api_key.txt`.
- GitHub remote: `https://github.com/zmin511/AutoSet.git`.
