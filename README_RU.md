# zmin_autoset

Версия: `1.5.2`

`zmin_autoset` - локальное portable-приложение для DJ-библиотеки **Denon Engine DJ**.
Оно помогает быстро собрать гармоничный сет вокруг выбранного опорного трека,
проверить трек по waveform/cue/loop и при необходимости создать плейлист прямо
в базе Engine без облака, аккаунтов и внешних сервисов.

## Зачем нужен проект

Проект закрывает практическую задачу подготовки DJ-сета:

- выбрать трек, от которого строится подбор;
- найти совместимые треки по BPM, Camelot, жанру/стилю и длине;
- учесть примерную энергию треков по Engine waveform;
- получить готовую папку с сетом или плейлист внутри Engine DJ;
- сохранить рядом `playlist.m3u`, `playlist.csv` и краткую методику подбора.

## Как это работает

Engine хранит библиотеку в SQLite-базе:

```text
Engine Library/Database2/m.db
```

`zmin_autoset` читает таблицы `Track` и `PerformanceData`:

- `Track` - путь к файлу, artist/title/genre, BPM, key, length, bitrate, доступность;
- `PerformanceData.overviewWaveFormData` - цветная overview-waveform, похожая на Engine;
- `PerformanceData.quickCues` - Cue 1..8 с позициями и подписями;
- `PerformanceData.loops` - Loop 1..8 со start/end и подписями.

Подбор сета выполняется скорингом переходов. Алгоритм учитывает:

- окно BPM относительно опорного трека и максимальный шаг BPM между соседними треками;
- расстояние по кругу Camelot и смену A/B;
- жанровые семейства и выбранные стиль-фильтры;
- примерную энергию, рассчитанную из `overviewWaveFormData`;
- длину трека, битрейт и повторяющиеся версии одного и того же трека.

Есть две роли опорного трека:

- `Начало` - трек становится opener, дальше BPM/энергия плавно растут;
- `Кульминация` - трек считается peak-точкой, до него строится подводка, после него энергия снижается.

## Интерфейс

Приложение запускает локальный Python-сервер и открывает UI в браузере.

В UI есть:

- настройка путей к `Music/` и `Engine Library`/`m.db`;
- браузер папок музыкальной библиотеки;
- поиск по базе Engine;
- таблица треков с жанром, Camelot, BPM и длительностью;
- индикаторы наличия cue и loop;
- встроенный аудиоплеер;
- Engine-like waveform с cue сверху и loop снизу;
- выбор роли трека, длительности, `Camelot +/-`, `BPM +/-`;
- фильтр стилей;
- создание сета с копированием файлов;
- создание плейлиста прямо в Engine DB;
- обновление тегов/жанров для выбранной папки.

## Основные инструменты

- `set_app/set_app.py` - локальный HTTP-сервер, REST API, запуск браузера и интеграция UI с инструментами.
- `set_app/index.html` - браузерный интерфейс.
- `tools/engine_set_builder.py` - основной алгоритм построения сета.
- `tools/engine_config.py` - общая конфигурация путей.
- `tools/engine_write_tags.py` - запись BPM/key/bitrate из Engine в ID3-теги файлов.
- `tools/review_new_genres.py` - нормализация жанров, семейств, DJ-стилей и служебных тегов.
- `tools/engine_db_playlist.py` - CLI-инструмент для чтения Engine DB и простых плейлистов.
- `tools/tag_from_musicbrainz.py` - дополнительный теггер по MusicBrainz/iTunes.

## Быстрый старт

Рекомендуемая структура на диске:

```text
<корень SSD или диска>/
  zmin_autoset/
  Music/
  Engine Library/
    Database2/
      m.db
```

Запуск:

- Windows: `zmin_autoset\run_windows.cmd`
- macOS: `zmin_autoset/run_mac.command`

UI откроется в браузере, обычно:

```text
http://127.0.0.1:8765/
```

## Результаты

Режим **Создать сет**:

```text
Music/Sets/<имя_сета>/
  01 - ...
  02 - ...
  playlist.m3u
  playlist.csv
  methodology.txt
```

Режим **Создать плейлист**:

- создает плейлист в базе Engine ссылками на существующие треки;
- дополнительно сохраняет локальные `m3u/csv` для проверки и предпрослушивания.

Поле `Event` в интерфейсе задает путь папки внутри Engine, например:

```text
Event
Event/Afro house
```

## Важно

- Не открывай `set_app/index.html` напрямую: для реальной работы нужен локальный Python-сервер.
- Перед записью плейлистов в Engine лучше закрыть Engine DJ или убедиться, что база не используется.
- Папки `Set`/`Sets` защищены от автоматического обновления тегов.
- Поддерживаемый рабочий провайдер библиотеки сейчас - Denon Engine DJ; rekordbox/Traktor только детектируются как будущие кандидаты.
