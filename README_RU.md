# AutoSet

Версия: `1.5.17`

`AutoSet` - локальное portable-приложение для **Denon Engine DJ**. Оно
помогает собрать гармоничный DJ-сет от выбранного опорного трека, проверить
трек по waveform/cue/loop и создать плейлист прямо в базе Engine без облака,
аккаунтов и внешних сервисов.

## Цель проекта

Проект нужен для быстрой подготовки DJ-сета:

- выбрать опорный трек;
- найти музыкально совместимые треки;
- выстроить последовательность по BPM, Camelot, жанру/стилю и энергии;
- получить готовую папку с сетом или плейлист внутри Engine DJ.

## Как работает

Главный источник данных - SQLite-база Engine:

```text
Engine Library/Database2/m.db
```

Приложение читает:

- `Track` - путь к файлу, artist/title/genre, BPM, key, length, bitrate;
- `PerformanceData.overviewWaveFormData` - цветную overview-waveform;
- `PerformanceData.quickCues` - Cue 1..8 с позициями и подписями;
- `PerformanceData.loops` - Loop 1..8 со start/end и подписями.

Алгоритм подбора оценивает соседние переходы:

- разницу BPM;
- расстояние по числам Camelot: `±3` от `5A/5B` дает 5, 6, 7, 8 и 4, 3, 2; A/B не увеличивает расстояние;
- близость жанров и выбранных стилей;
- примерную энергию из waveform;
- длину и битрейт;
- похожие версии одного трека.

## Интерфейс

UI открывается в браузере через локальный Python-сервер. В интерфейсе есть:

- настройка путей к `Music/` и `Engine Library`/`m.db`;
- браузер музыкальных папок;
- поиск по базе Engine;
- таблица треков с жанром, энергией в звездочках, Camelot, BPM и длительностью;
- индикаторы cue и loop;
- встроенный аудиоплеер;
- waveform с cue сверху и loop снизу;
- настройки роли трека, длительности, `Camelot +/-`, `BPM +/-`;
- фильтр стилей;
- кнопки создания сета и плейлиста;
- обновление тегов для выбранной папки;
- добавление, замена и удаление жанров/тегов для текущей папки или папки с подпапками;
- запись рассчитанной waveform-энергии в звездочки `Track.rating` Engine DJ для текущей папки или всей медиатеки `Music`.

## Режимы результата

**Создать сет** копирует треки в отдельную папку:

```text
Music/Sets/<имя_сета>/
  01 - ...
  02 - ...
  playlist.m3u
  playlist.csv
  methodology.txt
```

**Создать плейлист** создает плейлист в Engine DB ссылками на существующие
треки. Дополнительно сохраняются локальные `m3u/csv` для проверки.

Поле `Event` задает папку внутри Engine, например:

```text
Event
Event/Afro house
```

## Основные файлы

- `set_app/set_app.py` - локальный сервер, API и интеграция с Engine DB.
- `set_app/index.html` - браузерный интерфейс.
- `tools/engine_set_builder.py` - алгоритм построения сета.
- `tools/engine_config.py` - общая конфигурация путей.
- `tools/engine_write_tags.py` - запись Engine BPM/key/bitrate в ID3-теги.
- `tools/review_new_genres.py` - нормализация жанров, семейств и DJ-тегов.

## Быстрый старт

Рекомендуемая структура:

```text
<корень диска>/
  AutoSet/
  Music/
  Engine Library/
    Database2/
      m.db
```

Запуск:

- Windows: `AutoSet\run_windows.cmd`
- macOS: `AutoSet/run_mac.command`

UI обычно открывается здесь:

```text
http://127.0.0.1:8765/
```

Не открывайте `set_app/index.html` напрямую: для работы нужен локальный Python-сервер.
